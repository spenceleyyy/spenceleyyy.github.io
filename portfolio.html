Travel Buddy

Camera-first translator that reflows new language directly on top of the photo.

Photo, voice, and typed translations in one flow.

Built for travelers: point the camera, detect the language, translate on top of the image, and save the result.

iOS-ready On-device OCR Offline cache

Install on iPhone

  1. Download `travel-buddy-ios-setup.command` and double-click it.
  2. When Xcode opens, click Run to install on your iPhone.
  3. On first launch, trust the developer profile in Settings.

Requires Node.js, Xcode, and an Apple developer account. Re-run the script after any UI changes.

One-time setup details

  1. Add `native/ios/TravelBuddyTranslatePlugin.swift` to the App target for offline translation.
  2. Add NSCameraUsageDescription in Info.plist and set the deployment target to iOS 17+.

Offline mode

Travel Buddy caches recent translations locally. For full offline translation, add the iOS plugin file and download language packs in Settings > Translate (requires iOS 17+).

Test on iPhone

  2. Open `http://YOUR-IP:8000/gym-login.html` on your iPhone.
