Set Up Daily Health Sync
Create a Shortcut on your iPhone to send today's health data to Let's Go automatically every morning.
1
Open Shortcuts → tap +
Create a new blank Shortcut. Give it a name like "Let's Go Sync".
2
Add "Find Health Samples" actions
Add one action each for Steps, Active Energy Burned, Resting Heart Rate, and Body Mass. Set each to summarize for "Today". Save each result to a named variable.
3
Add an "Open URL" action
Paste the URL below. Replace each bracketed placeholder with the matching variable from step 2, and replace [Date] with a "Format Date" action set to ISO-8601.
4
Automate it
Automation tab → + → Time of Day → 8:00 AM, Daily → select your shortcut → disable "Ask Before Running". Data syncs while you sleep.
